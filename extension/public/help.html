Saral
Browser Copilot · v2.4

Make it simple.

Saral turns difficult government notices, circulars and official webpages into plain language you can read, translate and listen to — without leaving the page you are on.

How to use it

  1. Open the government page or circular you want to understand.
  2. Click the Saral icon in the Chrome toolbar.
  3. Press Read Active Tab to collect the main content — or highlight a passage first and Saral will use your selection instead.
  4. Review the text in the box. Nothing is sent until you press Simplify.
  5. Use Translate for Kannada and Read Aloud for audio.

Keyboard: press Alt + S on any page to open Saral.

What the popup can do

Read Active Tab Extracts the readable content of the current page and shows it for review before anything is sent.
Attach a document PDF, JPG, PNG, TXT and DOCX up to 10 MB, read by your own Saral backend.
Paste a URL Official portal URLs are fetched by the backend, which keeps its own SSRF protection in place.
Simplify Rewrites the text for a grade-5 reading level and checks that dates, amounts and requirements are preserved.
Translate English and Kannada are supported by the backend translation model today.
Read Aloud Generates a real audio file on the backend and plays it in the popup.

Backend address

Saral sends every request to your own Saral FastAPI backend. The default is http://127.0.0.1:8000. To point the extension at a deployed backend, open the popup, click the profile button in the header and change the address.

When you choose a host other than 127.0.0.1 or localhost, Chrome asks you to allow access to that host once. Saral never stores API keys — the backend keeps them server side.

Start the backend with:
cd backend && python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Permissions, and why they are needed

  • activeTab — reads the page you are on, only after you click Read Active Tab.
  • scripting — injects the small text extractor into that page on demand.
  • storage — remembers the backend address you typed, nothing else.
  • Host access — limited to your backend host, and requested per host only if you change the address.
Privacy: Saral never uploads a page automatically, never collects browsing history or open tabs, and never writes into the page you are reading. Only the text you approve is sent to your backend.

Current limitations

  • Hindi is not available yet. The backend translation model supports English and Kannada only, so the Hindi option in the popup is shown as unavailable rather than silently returning English.
  • Pages that block extensions — Chrome settings, the Chrome Web Store, the built-in PDF viewer and other restricted URLs — cannot be read.
  • The reading-grade badge only appears when the backend actually measured the text.
  • Scanned PDFs need Tesseract OCR installed on the machine running the backend.
